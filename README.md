# Reflection Questions

## 1. What accessibility challenges did you face, and how did you address them?
I think, if any, it would be overall making sure I got all the things done—meeting all the accessibility requirements. Trying to do all this in about 2 days with tons of sidequests (class and life) is tough, but I addressed them with patience and perseverence, can't say the same about the responsiveness though.

## 2. How did you ensure that your design was responsive and accessible for all users?
This was pretty easy, even though I am sure I over-coded this project. I like using semantic HTML in hopes to minimize my need for ARIA but I'm absolutely sure the site isn't completely accessible to all, I'd need way more time because the media queries aren't working... I did change the color of the bkg at 800px but `display: flex` was being blocked by something and I haven't found it.

## 3. What tools or resources did you find most helpful during this project?
This time I did a really brief 30min wireframe of the project in figma before starting; I also used figma to create the logos and hero image. As for resources, I used: MDN; W3 Schools; Web.dev—which I found to be the most helpful reference besides google.
